== Description ==

BDC News Desk is a professional WordPress theme for online newspapers and
digital media publications. It ships with a Bengali-first demo homepage,
a branded Elementor widget library, and an Appearance -> BDC News Desk
admin dashboard for setup and one-click demo content.

== Installation ==

1. Activate the theme from Appearance -> Themes.
2. Visit Appearance -> BDC News Desk and click "Import Demo Content" to
   create the sample categories, articles, and navigation menu.
3. Set a custom logo from Appearance -> Customize -> Site Identity.
4. Optional: activate Elementor to use the "BDC News Desk" widget category.

== Frequently Asked Questions ==

= Does this theme require Elementor? =

No. Every template (homepage, single post, archive, search, 404) works
with core WordPress content. Elementor only adds an optional branded
widget library for building extra pages/layouts.

= Where do I change the site tagline? =

Settings -> General, as with any WordPress site. The theme does not
lock or override it.

= How do I remap a homepage section to a different category? =

Appearance -> BDC News Desk -> "Homepage Section Categories".
